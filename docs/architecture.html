k3d + ArgoCD app-of-apps · CI en GitHub Actions · auto-PR · observabilidad · todo por IaC

CI/CD Pipeline (GitHub Actions)

  • • Push a un app-repo dispara el workflow
  • • Build + test + escaneo (Trivy)
  • • docker build → push a GHCR (tag = SHA)
  • • Auto-PR a k8s-workloads con el nuevo tag
  • • Merge → ArgoCD despliega solo

GitOps & IaC

  • • Pulumi (k8s-cluster) crea el k3d cluster
  • • Bootstrap de ArgoCD por IaC
  • • app-of-apps: 1 root app → todo lo demas
  • • auto-sync + self-heal + prune
  • • sealed-secrets para secretos en Git

Observabilidad

  • • Prometheus + kube-state + node-exporter
  • • Grafana con dashboards provisionados
  • • Loki + Promtail para logs centralizados
  • • Alertmanager → Slack/Telegram/email
